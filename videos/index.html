Покажем, как работать с Honer AI: от первого запроса до файлов, памяти и подключённых сервисов. На экране — настоящая запись приложения. Начните с конкретной задачи. Укажите цель, исходные данные и нужный формат результата.

Например: план встречи на двенадцать человек, срок — неделя, ответ — по трём этапам. Так проще получить полезный первый вариант. Ответ можно уточнять. Попросите сократить текст, изменить тон или подробно разобрать один пункт.

Не обязательно переписывать весь запрос: следующий вопрос может продолжать уже начатый разговор. Для списка задач удобна таблица. Назовите нужные столбцы и проверьте значения. Если нужен документ, попросите поддерживаемый формат и откройте созданный файл.

Сначала посмотрите результат, затем используйте его в работе. Память помогает сохранить важные предпочтения. Попросите запомнить, например, краткий стиль ответа. Затем откройте список и проверьте запись.

Демонстрационную запись можно изменить или удалить. Не сохраняйте здесь то, что не хотите использовать в будущих разговорах. Для личных репозиториев откройте Настройки, Интеграции, GitHub. Вставьте токен с доступом только к нужному проекту и проверьте подключение.

Вход через GitHub этого доступа не заменяет. Здесь мы читаем публичный README без подключения личного аккаунта. Яндекс.Диск подключается отдельно: Интеграции, Яндекс.Диск, Подключить через Яндекс. Пользователь входит в браузере, подтверждает доступ и возвращается в приложение.

Затем проверяет подключение. В нашем демо доступ не предоставлялся — показываем экран настройки. Для Railway нужен личный API-токен аккаунта. Его вводят в настройках интеграции.

После проверки доступны проекты и статусы развёртываний. Повторный деплой использует прикреплённый коммит и сам не забирает новый код из GitHub. В настройках выберите удобный язык интерфейса и доступные параметры. Язык меню и содержание ответа — разные вещи: нужный язык и стиль текста можно отдельно указать в самом запросе.

Для изображения опишите сюжет, композицию и настроение. Дождитесь готового результата и откройте его. Картинка в трёхмерном стиле остаётся иллюстрацией — это не интерактивная 3D-модель. Вопрос по приложению можно адресовать команде через раздел поддержки.
